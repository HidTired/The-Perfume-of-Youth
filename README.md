# TPY — The Perfume of Youth - Демонстрационный интернет-магазин парфюмерии на **PHP + Python + SQLite**.

## Возможности

- Главная страница с баннером и подборкой ароматов.
- Каталог с фильтрами
- Карточка товара с фотографией, ценой, описанием и нотами.
- Регистрация, вход и выход из аккаунта.
- Корзина, сохраняющаяся в SQLite между входами.
- Оформление заказа, сохранение состава заказа и истории.
- Добавление и удаление карты.
- Отзывы с оценками; просмотр и публикация доступны только после входа.
- Страница «О нас» и адаптивный дизайн для телефонов.

## Требования

1. Python 3.9 или новее.
2. PHP 8.1 или новее с расширением `pdo_sqlite`.

Для Windows удобно установить PHP через [официальный сайт PHP](https://windows.php.net/download/). 

## Быстрый запуск

Распакуйте папку `TPY`, откройте терминал в этой папке и выполните:

```bash
python setup.py
php -S localhost:8000
```

На Windows `py`.

Откройте в браузере **http://localhost:8000**.

Если порт 8000 занят, используйте `php -S localhost:8080` и откройте `http://localhost:8080`.

## Проверка функций

1. Откройте главную страницу и перейдите в каталог.
2. Зарегистрируйте тестовый аккаунт (пароль не короче 8 символов).
3. Добавьте несколько товаров в корзину и обновите страницу: товары сохранятся.
4. Оформите тестовый заказ. Он появится в разделе «История заказов», а корзина очистится.
5. В личном кабинете добавьте название тестовой карты и четыре последние цифры **вымышленной** карты, например `1234`.
6. Откройте «Отзывы», выберите товар и оставьте оценку с текстом.
7. Выйдите и снова войдите: история заказов и сохраненные записи останутся.

## Как устроена моя база

| Таблица | Назначение |
| --- | --- |
| `users` | Пользователи и хеши паролей |
| `products` | Каталог ароматов и сертификатов |
| `cart_items` | Сохраненные товары и количество |
| `orders` | Заказы, итоговая стоимость и дата |
| `order_items` | Снимок состава заказа и цены на момент оформления |
| `reviews` | Отзывы, рейтинг, автор и товар |
| `saved_cards` | Только название и последние четыре цифры тестовой карты |
